# BMI-CALCULATOR-PYTHON
interface built using Python and TkinterA simple and user-friendly Body Mass Index (BMI) calculator with a graphical.

## Features

- Calculate BMI using weight (kg) and height (cm)
- User-friendly graphical interface
- Real-time BMI category display
- Input validation
- BMI category reference guide

## Requirements

- Python 3.x
- Tkinter (usually comes pre-installed with Python)

## Installation

1. Clone or download this repository
2. Navigate to the project directory
3. Run the application:
   ```
   python bmi_calculator.py
   ```

## How to Use

1. Enter your weight in kilograms
2. Enter your height in centimeters
3. Click the "Calculate BMI" button
4. Your BMI and category will be displayed

## BMI Categories

- Underweight: < 18.5
- Normal weight: 18.5 - 24.9
- Overweight: 25 - 29.9
- Obese: ≥ 30

## Note

This BMI calculator is for informational purposes only and should not be used as a substitute for professional medical advice.
